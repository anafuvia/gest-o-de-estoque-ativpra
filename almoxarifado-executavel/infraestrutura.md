# ENTREGA 09 — Lista de Requisitos de Infraestrutura

## SGBD
- SQLite 3.
- No sistema, o banco SQLite é manipulado pela biblioteca `sql.js` 1.13.x.
- Arquivo persistido localmente: `sistema/almoxarifado_db.sqlite`.

## Linguagem de programação
- JavaScript.
- Runtime: Node.js 22 LTS.
- Front-end: HTML5, CSS3 e JavaScript ES6+.
- Back-end: Node.js com Express 5.1.x.

## Sistema operacional de desenvolvimento
- Windows 10 ou Windows 11, 64 bits.

## Software necessário
- Node.js 22 LTS.
- NPM.
- Navegador Google Chrome ou Microsoft Edge.
- Visual Studio Code, recomendado.
- Git, para publicação do repositório no GitHub.

## Requisitos mínimos sugeridos de hardware
- Processador dual-core.
- 4 GB de memória RAM.
- 500 MB de espaço livre para projeto, dependências e banco.
- Conexão com a internet para instalar dependências e publicar no GitHub.
